How To Play

Goal: Sort all colorful metallic nuts so that each bolt contains nuts of only one color.

  • Tap a bolt to lift its top nut.
  • Tap another bolt to place the nut.
  • A nut can only be placed onto an empty bolt or on top of a nut of the exact same color.
  • Each bolt holds a maximum of 4 nuts.
  • Use empty bolts as temporary sorting spots.
  • Tap Undo to reverse any move, or Hint if you get stuck!
